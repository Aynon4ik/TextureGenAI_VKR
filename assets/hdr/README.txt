HDR для 3D-превью (IBL, Three.js) — формат EXR:

  studio.exr   — студия (~1 МБ, 1K)
  outdoor.exr  — улица / небо (~5 МБ, 1K)

Переключатель «HDR сцена» меняет освещение и размытый фон.
Вьювер загружается только после «Показать на модели» (не при F5).

Poly Haven (скачать 1K EXR):
  https://polyhaven.com/a/studio_small_08
  https://polyhaven.com/a/kloofendal_43d_clear_puresky
