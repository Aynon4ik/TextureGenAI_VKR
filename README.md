# TextureGen AI

Система автоматизированной генерации текстур для 3D-моделей на основе референсных изображений и текстовых описаний с использованием нейросетевых технологий. Приложение объединяет генерацию изображений (Stable Diffusion 1.5), классификацию типа материала (ResNet-18), ML-агента подбора параметров, бесшовную обработку, эвристическое построение PBR-карт и интерактивный 3D-просмотр.

## Требования

- Python 3.10+
- Windows 10/11 или Linux

## Установка

### 1. Создание виртуального окружения

```bash
cd texture-gen-system
python -m venv venv
venv\Scripts\activate
```

### 2. Установка PyTorch с поддержкой CUDA

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

### 3. Установка остальных зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Приложение откроется на http://localhost:7860 (при занятом порте выбирается следующий свободный).

## Вкладки приложения

- **Генерация** — img2img по референсу (с авто- или ручным выбором типа материала) и txt2img по текстовому описанию; галерея вариантов.
- **ML-Агент** — автоматический перебор стратегий параметров с оценкой качества и досрочной остановкой по порогу.
- **Просмотр** — построение PBR-карт (Albedo, Normal, Roughness, AO, Height), бесшовная обработка, 3D-превью на примитивах с HDR-освещением и экспорт PNG/ZIP.

## Модули системы

| Модуль | Назначение | Модель/Метод |
|--------|-----------|--------------|
| Классификатор | Определение типа материала | ResNet-18 (transfer learning) |
| Генератор (img2img) | Генерация текстуры по референсу | Stable Diffusion 1.5 |
| Генератор (txt2img) | Генерация текстуры по описанию | Stable Diffusion 1.5 |
| ML-агент | Подбор параметров и отбор лучшего кадра | Стратегии + составная метрика качества |
| Seamless-процессор | Бесшовная обработка | Roll & Blend |
| PBR-генератор | Normal, Roughness, AO, Height | Эвристика из albedo (Sobel / Gaussian) |

## Примечания

- При первом запуске веса Stable Diffusion (~4 GB) загружаются автоматически с Hugging Face — для первой генерации нужен интернет.
- Веса классификатора входят в репозиторий; обучающий датасет не входит.
- Генерация одного изображения занимает ~5–10 секунд на RTX 4060.
