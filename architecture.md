# Архитектура TextureGen AI

Проект — монолитное локальное веб-приложение на Python: один процесс, без отдельного API-сервера и без СУБД. Данные и артефакты хранятся в файлах на диске (веса классификатора, кэш моделей Hugging Face, экспорт PBR и GLB-превью).

---

## Точка входа

| Файл | Роль |
|------|------|
| `app.py` | Интерфейс Gradio (`gr.Blocks`), три вкладки, обработчики событий, ленивая загрузка моделей |

Генератор и классификатор создаются как единственные экземпляры при первом обращении пользователя.

---

## Слой интерфейса (три вкладки)

1. **Генерация** — переключатель «По референсу» / «По описанию»:
   - по референсу — img2img с авто- или ручным выбором типа материала;
   - по описанию — txt2img по текстовому промпту;
   - модуль `src/generator.py`, Stable Diffusion 1.5.
2. **ML-Агент** — автоматический перебор стратегий параметров с оценкой качества и досрочной остановкой по порогу; модуль `src/agent.py` использует генератор и классификатор.
3. **Просмотр** — построение PBR-карт, опциональная бесшовная обработка, 3D-превью на примитивах с HDR-освещением и экспорт PNG/ZIP; модули `src/pbr.py`, `src/seamless.py`, `src/preview3d.py`, `src/preview_env.py`, `src/preview_viewer.py`.

---

## Слой логики (`src/`)

| Модуль | Роль |
|--------|------|
| `generator.py` | Img2img / txt2img, промпты материалов |
| `classifier.py` | ResNet-18, 5 классов, `models/texture_classifier.pth` |
| `classifier_model.py` | Построение модели классификатора |
| `materials.py` | Классы материалов, промпты, подписи UI |
| `agent.py` | Итеративный подбор параметров, метрики качества |
| `seamless.py` | Бесшовность, 2D-превью тайлинга |
| `pbr.py` | Эвристическое построение PBR-карт из albedo |
| `preview3d.py` | Примитивы, UV-тайлинг, экспорт GLB |
| `preview_env.py` | HDR-окружение для 3D-превью |
| `preview_viewer.py` | Встроенный просмотрщик (iframe / Three.js) |

---

## Потоки данных

**Генерация:** референс или текст + тип материала → галерея PNG.

**Агент:** референс → лучший кадр + отчёт (при «Авто» внутри вызывается классификатор).

**Просмотр:** текстура → PBR-карты → опциональная бесшовная обработка → 3D-превью (GLB) + плоское превью тайлинга → экспорт PNG/ZIP.

---

## Технологии

| Область | Стек |
|---------|------|
| UI | Gradio |
| Генерация | PyTorch, Diffusers, Stable Diffusion 1.5 |
| Классификация | ResNet-18 (torchvision) |
| 3D | trimesh → GLB, Three.js (просмотрщик), HDR |
| Изображения и PBR | Pillow, NumPy, SciPy |
| Метрики агента | scikit-image (SSIM) |

---

## Схема связей

```
[Браузер] → Gradio (app.py)
              ├── Генерация → generator.py (+ classifier при «Авто»)
              ├── ML-Агент  → agent.py → generator, classifier
              └── Просмотр  → pbr.py, seamless.py, preview3d.py → GLB + HDR-превью
```
